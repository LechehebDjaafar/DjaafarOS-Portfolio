# DjaafarOS — بورتفوليو على شكل نظام تشغيل

بورتفوليو تفاعلي يحاكي نظام تشغيل كامل (Windows 11 / macOS / Linux GNOME + وضع Android تلقائي
على الهاتف)، مع شاشة إقلاع سينمائية، Terminal تفاعلي، إنجازات مخفية، وألعاب صغيرة.

## 🚀 رفعه على GitHub Pages (خطوة بخطوة)

1. أنشئ مستودع (repository) جديد على GitHub، مثلاً باسم `Portfolio` أو `MyPortfolio`.
2. ارفع كل محتوى هذا المجلد (`index.html`, `data/`, `images/`, `docs/`) إلى جذر المستودع.
3. من إعدادات المستودع → **Settings → Pages** → اختر **Branch: main** والمجلد **/ (root)** → Save.
4. بعد دقيقة أو دقيقتين سيصبح البورتفوليو متاحاً على رابط من شكل:
   `https://اسم-حسابك.github.io/اسم-المستودع/`

> ملاحظة: البورتفوليو يحمّل `data/projects.json` عبر `fetch`، وهذا يعمل بشكل طبيعي على GitHub
> Pages. إذا فتحت `index.html` مباشرة من جهازك (بدون سيرفر)، بعض المتصفحات تمنع هذا النوع من
> التحميل المحلي — في هذه الحالة يعرض البورتفوليو قائمة المشاريع الافتراضية المدمجة في الكود
> بدلاً من ذلك (لا يتعطل شيء). للتجربة المحلية الكاملة، شغّل سيرفر بسيط داخل المجلد:
> `python3 -m http.server` ثم افتح `http://localhost:8000`.

## 📁 كيف تضيف مشروعاً جديداً (بدون لمس الكود)

افتح `data/projects.json` وأضف كائن جديد لأي مشروع تنجزه مستقبلاً:

```json
{
  "name": "اسم المشروع",
  "tags": ["Python", "Django"],
  "desc": "وصف قصير عن المشروع.",
  "image": "images/projects/my-project.jpg",
  "link": "https://github.com/username/repo",
  "docs": ""
}
```

- `image` و `link` و `docs` اختيارية — اتركها `""` إن لم تكن متوفرة.
- المشروع سيظهر تلقائياً في نافذة **Projects** داخل البورتفوليو وفي أمر `projects` بالطرفية.
- **إذا وضعت `link` (رابط الموقع المباشر) بدون `image`**: تظهر أيقونة المشروع تلقائياً بشكل
  أيقونة موقع حقيقية (favicon الموقع) بدل الأيقونة الافتراضية — تماماً كما في بورتفوليوك القديم.
  إذا وضعت `image` (لقطة شاشة) فهي تُستخدم أولاً وتتجاوز الـ favicon.

## 🖼️ كيف تضيف صوراً

ضع الصورة داخل `images/projects/` واربطها في `projects.json` كما بالمثال أعلاه.
التفاصيل الكاملة في `images/README.md`.

## 📄 كيف تدير سيرك الذاتية (أكثر من CV حسب المجال)

عدّل `data/cvs.json` وأضف كائن لكل سيرة ذاتية تخصصية تملكها:

```json
[
  {"title":"السيرة الذاتية العامة", "domain":"General / Full-Stack", "file":"docs/resume.pdf"},
  {"title":"سيرتي في مجال IoT", "domain":"IoT & Embedded", "file":"docs/resume-iot.pdf"},
  {"title":"سيرتي في الذكاء الاصطناعي", "domain":"AI & Data", "file":"docs/resume-ai.pdf"}
]
```

ضع ملف الـ PDF المطابق داخل `docs/` بنفس الاسم في `file`. كل سيرة ستظهر كبطاقة منفصلة بزر
تحميل خاص بها في نافذة **CVs** بالبورتفوليو. لإضافة مستندات مشاريع أخرى (تقارير، شهادات...)
راجع `docs/README.md`.

## 🔗 روابط منصات التواصل الاجتماعي

عدّل `data/social.json` وضع روابط حساباتك:

```json
{
  "instagram": "https://instagram.com/username",
  "facebook": "https://facebook.com/username",
  "linkedin": "https://www.linkedin.com/in/username",
  "youtube": "https://youtube.com/@username"
}
```

أي منصة تتركها فارغة (`""`) لن تظهر أيقونتها. الأيقونات تظهر تلقائياً في نافذة **Contact**
داخل البورتفوليو بمجرد إضافة الروابط.

## 🎮 الألعاب المدمجة

من أيقونة **Games** على سطح المكتب، أو مباشرة من الـ Terminal:

- `snake` — لعبة الثعبان الكلاسيكية.
- `tictactoe` — إكس-أو ضد الجهاز.
- `memory` — لعبة الذاكرة (طابق الأزواج).

## 🗂️ هيكلة المشروع

```
.
├── index.html          ← الملف الرئيسي (كل الواجهة والمنطق)
├── data/
│   ├── projects.json   ← عدّل هذا الملف لإضافة/تعديل مشاريعك
│   ├── cvs.json         ← قائمة سيرك الذاتية (واحدة أو أكثر حسب المجال)
│   └── social.json      ← روابط Instagram / Facebook / LinkedIn / YouTube
├── images/
│   └── projects/       ← صور (لقطات شاشة) المشاريع
└── docs/
    ├── resume.pdf       ← سيرتك الذاتية العامة (استبدلها بالحقيقية)
    └── resume-*.pdf      ← أضف سيراً ذاتية إضافية هنا وسجّلها في data/cvs.json
```

## ⚙️ التخصيص العام

المعلومات الشخصية الأساسية (الاسم، المسمى الوظيفي، المهارات، الخبرات...) موجودة داخل كائن
`const P = {...}` في أعلى قسم `<script>` بملف `index.html`، وتقدر تعدلها مباشرة في أي وقت.
