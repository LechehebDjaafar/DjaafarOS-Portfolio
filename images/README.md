# مجلد الصور

ضع هنا صور مشاريعك. المسار المقترح لكل مشروع:

```
images/projects/اسم-المشروع.jpg
```

ثم في `data/projects.json` ضع نفس المسار في حقل `image`، مثال:

```json
{
  "name": "AI-Powered Smart Irrigation",
  "image": "images/projects/smart-irrigation.jpg"
}
```

- إذا تركت `image` فارغاً (`""`) ستظهر أيقونة ملف افتراضية بدلاً من الصورة، فلا داعي للقلق إن لم تملك صورة بعد.
- أي صيغة صور شائعة تعمل: `.jpg` `.png` `.webp`.
- يفضّل أن تكون الصورة بنسبة عرض إلى ارتفاع قريبة من 16:9 لتظهر بشكل جيد داخل البطاقة.
